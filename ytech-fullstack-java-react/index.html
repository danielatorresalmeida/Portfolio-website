Dominant case study

DevFlowHub: full-stack delivery in practice.

Project overview

DevFlowHub is an in-progress platform for managing developers, projects, Agile tasks, and internal development programmes. It connects a React + TypeScript + Vite frontend to Java and Spring Boot REST APIs with PostgreSQL persistence.

The problem

The platform brings project work, task status, people, and development programmes into one structured workflow while protecting account and API operations.

My contributions

  • Worked across frontend integration, backend API behaviour, relational data, security, migrations, testing, and debugging.
  • Implemented and tested JWT authentication, Spring Security rules, protected /api/** routes, inactive-user restrictions, consistent 401 responses, and password changes based on the authenticated JWT subject.
  • Added backend-controlled audit fields, kept createdAt immutable, maintained updatedAt automatically, and supported the change with a database migration.
  • Preserved microsecond timestamp precision and validated behaviour with controller, unit, persistence, and API smoke tests.

Integration and debugging

I investigated React-to-Spring requests, authentication failures, local ports and environment configuration, migration behaviour, and the relationship between frontend requests and backend security responses.

Workflow

Work is broken into structured tasks and incremental changes, using feature branches, pull requests, implementation notes, test evidence, and review of security, migrations, and data integrity before merging.

Current status and next work

The project is actively being developed. The next focus is continuing the core management workflows, strengthening integration coverage, and refining error handling and user feedback as features mature.
