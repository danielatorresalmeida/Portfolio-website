OPUS

A classical music library built with Laravel: composer and work catalogues, research tools and carefully controlled data imports.

View source codeInstallation instructions

What I built

Core functionality

Composer and work catalogue

Search, musical-period and work-count filters, sorting, pagination and detailed records.

Authentication and permissions

Public browsing, authenticated favourites and editing, with creation, deletion and imports restricted to administrators.

Classical music API integration

Selective Open Opus imports by external ID, duplicate checks, preservation of local edits, transactions and error handling.

Images, scores and sources

Optional images and PDF score uploads, file validation and links to specialist music research resources.

Implementation

Technical approach

Browser + Blade views → Laravel routes and controllers → Eloquent models → MySQL
Laravel HTTP client → Open Opus external API
Laravel public filesystem → Images and PDF scores
